# Speaking 추가 수행평가 기능 명세

- 지면 위치: 평가문제집 39쪽
- 새 소재: Future Skills Fair Pitch
- 과제: 친구들에게 미래 기술 체험 부스 하나를 추천하는 45초~1분 발표
- 발표 구성: 추천할 미래 기술 부스 / 관심 분야와 이유 / 부스에서 할 활동 / 미래 직업과의 연결
- 필수 표현: I've decided to visit the ~ booth. / I'm interested in ~ because ~. / I'm planning to ~ there. / In the future, I want to become ~.
- 부스 선택: Robotics / Green Design / Media Creator
- 사용자 흐름: 부스 선택 → 아이디어 정리 → 필수 표현 확인 → 예시 대본 확인 → 대본 작성
- 지원 기능: 아이디어 기반 초안, 단어 수·예상 발표 시간·필수 표현 사용 수 표시, 브라우저 임시 저장
- 녹음·MP3 버튼: 화면만 구현하며 실제 동작은 연결하지 않음
- QR 고정 주소: /go/speaking-task/
