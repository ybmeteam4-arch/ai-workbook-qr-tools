Speaking Performance Task · Lesson 1

Future Skills Fair Pitch

친구들에게 미래 기술 체험 부스 하나를 추천하는 45초~1분 발표를 준비해 보세요.

45초–1분
1

추천할 부스 선택

관심 있는 미래 기술 부스를 골라 보세요.

2

발표 내용 구성

새로운 주제에 맞게 발표 핵심 내용을 정리해 보세요.

3

필수 표현

다음 표현을 발표 대본에 모두 활용해 보세요.

  • I've decided to visit the _____ booth.
  • I'm interested in _____ because _____.
  • I'm planning to _____ there.
  • In the future, I want to become _____.
4

예시 대본

발표의 흐름과 필수 표현 사용 방법을 확인해 보세요.

Hello, everyone. I've decided to visit the Robotics booth. I'm interested in robots because they can help people in many ways. I'm planning to build and control a simple robot there. I also want to ask the staff about the skills that robot engineers need. In the future, I want to become a robot engineer. I hope you will visit this exciting booth, too. Thank you.

5
