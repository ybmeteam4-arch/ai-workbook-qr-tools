# MY ERROR NOTE 기능 명세

- 지면 위치: 평가문제집 48쪽
- 목적: 평가문제집에서 틀린 문제를 분류하고, 오답 원인을 판단한 뒤 관련 코너를 복습하고 다시 푼다.
- 현재 데이터: 실제 채점 결과는 없으므로 임의 예시 1건만 제공하고 학생 기록 카드는 빈 상태로 시작한다.
- 예시: 5번·문법①·관계대명사의 계속적 용법 → 평가문제집 14쪽 Grammar Video 1
- 카드 입력: 문제 번호 / 영역 / 핵심 개념 / 복습 위치 / 오답 원인 / 다시 풀기·고쳐 쓰기
- 오답 원인: 개념 부족 / 본문 혼동 / 조건 누락 / 문제를 잘못 읽음 / 실수
- 영역별 복습 위치를 자동 제안하되 학생이 직접 수정할 수 있다.
- 카드 추가·삭제·전체 초기화와 브라우저 임시 저장을 지원한다.
- QR 고정 주소: /go/error-retry/
