# Writing 추가 수행평가 기능 명세

- 지면 위치: 평가문제집 38쪽
- 학습 목표: 미래 진로에 필요한 능력과 준비 계획을 필수 표현을 활용하여 5문장 이상 쓴다.
- 소재 1: My Future Skill Challenge
- 소재 2: My Future Teamwork Challenge
- 필수 표현: I've decided to become / I'm planning to learn 또는 practice / I need this skill because / In the future, I want to
- 사용자 흐름: 소재 선택 → 아이디어 정리 → 필수 표현 확인 → 예시 답안 확인 → 직접 쓰기
- 지원 기능: 아이디어 기반 초안 생성, 문장 수·필수 표현 사용 수 표시, 브라우저 임시 저장
- PDF 버튼: 화면만 구현하며 실제 다운로드 동작은 연결하지 않음
- QR 고정 주소: /go/writing-task/
