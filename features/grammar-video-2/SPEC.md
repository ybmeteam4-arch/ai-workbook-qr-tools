# Grammar Video 2 기능 명세

- 담당자: 작업자 B
- 지면 위치: 평가문제집 16쪽
- 현재 상태: 1차 구현 완료
- 학습 목적: Grammar Point 2 `too ... to`를 핵심 동영상으로 복습하고, Grammar Point 1 `관계대명사의 계속적 용법`과 함께 혼합 문제로 확인한다.
- 사용자 진행 순서: 핵심 동영상 시청 → Grammar 1·2 Mixed Quiz 6문항 풀이 → 자동 채점 → 결과 확인 → 전체 다시 풀기 또는 틀린 문제만 재도전
- 버튼과 동작: `자동 채점하기`는 정오·정답·해설을 표시한다. `전체 다시 풀기`는 6문항을 초기화한다. `틀린 문제만 재도전`은 직전 채점에서 틀린 문항만 다시 구성한다.
- 영상: Google Drive 파일 `언어형식 설명 동영상 2_too ~ to ....mp4`를 iframe preview로 사용한다. 공개 저장소에는 영상 파일 자체를 복제하지 않는다.
- 퀴즈 콘텐츠: 공개 저장소용 신규 샘플 문항 6개만 사용한다. 실제 평가문제집 문항·미공개 교재 원문은 사용하지 않는다.
- 저장: 직전 점수와 오답 문항 ID만 브라우저 `localStorage`의 `grammarVideo2LastResult`에 저장한다.
- 기능 이동: 이전은 Grammar Video 1 공통 화면, 다음은 Writing 추가 수행평가 전용 화면으로 연결한다.
