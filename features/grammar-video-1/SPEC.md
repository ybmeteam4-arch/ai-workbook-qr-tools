# Grammar Video 1 기능 명세

- 담당자: 작업자 A
- 지면 위치: 평가문제집 14쪽
- 현재 상태: 1차 구현 완료
- 학습 주제: 관계대명사의 계속적 용법
- 학습 목적: 개념 영상을 보고 계속적 용법의 형태와 쓰임을 이해한 뒤 5문항으로 확인
- 사용자 진행 순서: 개념 동영상 → 핵심 개념 정리 → 5문항 미니 퀴즈 → 자동 채점 → 오답 재도전
- 영상: Google Drive MP4, 링크가 있는 모든 사용자 보기
- 문항 구성: 빈칸 완성 2문항, 바른 문장 고르기 1문항, 의미 이해 1문항, 문장 연결 1문항
- 핵심 규칙: 쉼표 사용, 사람 who, 사물 which, 계속적 용법에서 that·관계대명사 생략 불가
- 완료 기준: PC·모바일 동일 기능 작동, 영상 재생, 자동 채점, 틀린 문제만 재도전
