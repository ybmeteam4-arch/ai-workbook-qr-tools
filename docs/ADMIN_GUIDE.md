# 평문 관리자 GitHub 관리 안내

## 매일 확인할 곳
1. 저장소 상단의 Pull requests를 선택합니다.
2. 새 요청이 있으면 Files changed에서 변경 파일을 확인합니다.
3. 담당 폴더 외 파일이 수정되었는지 확인합니다.
4. Conversation에서 질문이나 수정 의견을 남깁니다.
5. 검수가 끝난 경우에만 Merge pull request를 선택합니다.

## main 관리 원칙
- main은 최종 검수 완료 파일만 유지합니다.
- 공용 파일 변경은 평문 관리자가 승인합니다.
- 실제 교재 콘텐츠는 공개 저장소에 올리지 않습니다.

## GitHub Pages 공개 전
- 샘플 문구만 사용했는지 확인합니다.
- 로그인 없이 화면이 열리는지 확인합니다.
- PC와 휴대폰에서 이전·다음 버튼을 확인합니다.
