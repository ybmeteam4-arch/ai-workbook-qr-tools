# 작업자용 단계별 안내

1. 저장소의 Code 화면에서 브랜치 목록을 엽니다.
2. 자신의 작업 브랜치를 선택합니다.
3. `features/담당기능/` 폴더만 엽니다.
4. 먼저 SPEC.md를 수정합니다.
5. 구현 방향을 MOBILE.md에 기록합니다.
6. 기능 파일을 작업합니다.
7. 작업을 마칠 때 HANDOFF.md를 업데이트합니다.
8. Pull requests에서 New pull request를 선택합니다.
9. 자신의 브랜치를 compare, main을 base로 선택합니다.
10. 변경 내용과 확인 결과를 적고 평문 관리자에게 검토를 요청합니다.
